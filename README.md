# 🏠 RentWise Management System

**RentWise Management System** is a Python-based command-line application designed to simplify rent calculations and basic rental expense management.

## ✨ Features

- **Monthly Rent Calculator:** Calculate total rent using base rent, maintenance charges, parking charges, and discounts.
- **Rent Split Calculator:** Divide the total rent equally among multiple tenants.
- **Utility Expense Calculator:** Calculate electricity, water, internet, gas, and other expenses.
- **Rent Summary:** Generate a monthly rent summary containing property details, tenant details, rent breakdown, utility expenses, total amount due, and payment status.
- **Late Fee Calculator:** Calculate late payment charges based on overdue days and a specified grace period.
- **Annual Rent Projection:** Estimate annual rent and projected increases.
- **Text File Storage:** Save the rent summary in a `p.txt` file.

## 🛠️ Technologies Used

- Python 3
- File Handling
- Functions and Global Variables
- Exception Handling (`try-except`)
- Conditional Statements and `match-case`
- String Formatting and Date/Time Handling

## 📋 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd RENT_CALCULATOR
   ```

3. Run the application:

   ```bash
   python main.py
   ```

## 🖥️ Main Menu

The application provides the following options:
